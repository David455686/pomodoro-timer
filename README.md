# 番茄鐘計時器

一個簡潔優雅的 Python + PyQt6 番茄鐘桌面應用。

## 功能特性

- ⏱️ **標準番茄鐘**：25分鐘工作 + 5分鐘休息
- 🎚️ **自訂時間**：隨時調整工作和休息時長
- 🔔 **完成通知**：時間結束自動提醒（包括系統提示音）
- 📊 **統計計數**：追蹤完成的番茄鐘數量
- 🎨 **精美界面**：完整繁體中文 UI 介面

## 安裝步驟

### 1. 安裝依賴
```bash
cd pomodoro_timer
pip install -r requirements.txt
```

### 2. 運行應用
```bash
python pomodoro.py
```

或雙擊 `start.bat` (Windows)

## 使用說明

1. **開始計時**：點擊「開始」按鈕啟動番茄鐘
2. **暫停計時**：點擊「暫停」按鈕暫停（可隨時繼續）
3. **重置計時**：點擊「重置」按鈕回到初始狀態
4. **調整時間**：
   - 「工作時間」：設定每個工作週期的分鐘數（預設25分鐘）
   - 「休息時間」：設定休息週期的分鐘數（預設5分鐘）
5. **接收通知**：工作或休息時間結束時會彈出通知和提示音

## 系統需求

- Python 3.8+
- Windows / macOS / Linux
- PyQt6
